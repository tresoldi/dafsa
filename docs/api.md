    [`DESIGN.md`](https://github.com/tresoldi/dafsa/blob/master/DESIGN.md) and is built over

    layer; the user-facing structures (`Trie`, `Dafsa`, `CompactDafsa`, `SuffixAutomaton`,
    `Cdawg`, `Fst`) land in later milestones.
